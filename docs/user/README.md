# IFC Atlas User Documentation

An open-source IFC / BIM viewer with a built-in multi-LLM agent.

The published documentation site is at
[nbharathik.github.io/ifc-atlas](https://nbharathik.github.io/ifc-atlas/);
it is built from the files in this folder.

Start with [Getting Started](GETTING_STARTED.md), then [Features](FEATURES.md)
for the full catalogue, [Deploy Your Own](DEPLOY_YOUR_OWN.md) for hosting, and
[Running Tauri](RUNNING_TAURI.md) for the desktop build. Contributor and
architecture docs live in [`docs/architecture/`](../architecture/).
